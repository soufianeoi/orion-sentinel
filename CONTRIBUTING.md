# Contributing to Orion Sentinel

Thanks for your interest in contributing. We welcome bug reports, feature requests, and pull requests.

## Getting Started

1. **Fork** the repository
2. **Clone** your fork (`git clone https://github.com/your-username/orion-sentinel.git`)
3. **Create a branch** (`git checkout -b feature/your-feature`)
4. **Install dependencies** (see [README](README.md#quick-start))
5. **Make your changes**
6. **Test** your changes (`npm test` in backend and frontend directories)
7. **Commit** (`git commit -m 'Add feature'`)
8. **Push** (`git push origin feature/your-feature`)
9. **Open a Pull Request**

## Guidelines

### Code Style

- Backend: Node.js 20, ES2022, `const`/`let` over `var`, async/await
- Frontend: React 18, TypeScript, functional components with hooks
- Follow existing patterns in the codebase

### Pull Requests

- Keep PRs focused on a single concern
- Update documentation if needed
- Make sure the dashboard still loads without errors
- Reference any related issues

### Reporting Issues

- **Bug reports**: Include steps to reproduce, expected vs actual behavior, and environment details
- **Feature requests**: Describe the problem you're trying to solve, not just the solution
